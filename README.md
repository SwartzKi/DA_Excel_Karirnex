# Car Sales Excel Practice

## About

A mini project created to practice Excel for data analysis using car sales transaction data.

## Dataset

The dataset contains car sales transaction data, including sales date, branch, product, category, price, quantity, payment type, discount, total sales, and other related fields.

## Analysis Objectives

1. Explore and understand the car sales dataset.
2. Perform data cleaning and preparation.
3. Analyze sales transactions using Excel functions.
4. Summarize and compare sales data based on different categories.
5. Create visualizations to present the analysis results.

## Excel Concepts

- Data cleaning and preparation
- Data filtering and sorting
- Excel formulas and functions
- Data aggregation
- Pivot tables
- Data visualization

## Documentation

The PDF contains the analysis objectives, Excel analysis process, and the corresponding results. The content and explanations are written in Indonesian.
